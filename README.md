## Setup

  **必要環境**
  - Go 1.25以上

  **手順**

  1. リポジトリをクローン
     git clone https://github.com/recursion-gowebapi/go-web-api.git
     cd go-web-api

  2. サーバーを起動
     go run .

  3. ブラウザで開く
     http://localhost:8080
